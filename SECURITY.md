# Security / Seguridad

- The package contains instructions only: two skills in Markdown, their manifests and the license. It installs no hooks, servers or code. The code examples in the references (the approval line check and the machine hook) only run if someone copies them, or if the owner tells the agent to install the hook.
- Report vulnerabilities privately with "Report a vulnerability" in the repository's Security tab. Do not open a public issue. Do not include real secrets or personal data; describe the file, the line and how to reproduce it.
- Fixes are released in a new version from `main`.

- El paquete solo contiene instrucciones: dos skills en Markdown, sus manifiestos y la licencia. No instala ganchos, servidores ni código. Los ejemplos de código de las referencias (el check de la línea de aprobación y el gancho de equipo) solo corren si alguien los copia, o si el dueño le dice al agente que instale el gancho.
- Reporta las vulnerabilidades en privado con "Report a vulnerability", en la pestaña Security del repositorio. No abras un issue público. No incluyas secretos reales ni datos personales; describe el archivo, la línea y cómo reproducirlo.
- Las correcciones salen en una versión nueva desde `main`.
